# Search and agent-bot visibility: evidence and operating checks

Status: assessed 2026-09-25 for the canonical Astro SSG + Cloudflare Worker deployment. The decision is whether further crawler-specific machinery is warranted, not whether any engine has actually indexed or cited the site. See [migration validation](cloudflare-validation.md) for the deployed HTTP smoke checks.

## Judgment

Keep **canonical, crawlable HTML as the source of record**. The current static-site generation (SSG) build and Worker asset routing already supply the high-confidence prerequisites: real `200`/`404` responses, article text and links in the initial response, absolute canonical links, localized routes/alternates, sitemap, RSS, and a permissive `robots.txt`. Do **not** convert public content to client-only rendering or spend effort treating `llms.txt` as a ranking control. The material unverified questions are **indexing and actual Cloudflare bot-policy behavior**, not HTML presence.

## Research frontier and caution

The peer-reviewed [GEO study (KDD 2024)](https://doi.org/10.1145/3637528.3671900) reports that some source-content edits improved a *benchmark generative-engine visibility metric*, with effects varying by topic. This is evidence that content presentation can influence a synthesis system **after sources are available**, not evidence that adding `llms.txt`, JSON-LD, or a particular HTML framework makes a page discoverable across today's production assistants. A [2026 conference audit of Google AI Overview citations](https://proceedings.mlr.press/v318/kakimov26a.html) explicitly separates retrieval rank from citation selection in a YMYL-query sample, reinforcing that crawl/index status and later citation are different outcomes; its observational design and query domain do not establish a site-specific intervention here. By contrast, [Google's current AI-search guide](https://developers.google.com/search/docs/fundamentals/ai-optimization-guide) directly says conventional crawlability, indexing eligibility, useful content and page experience remain foundational, and eligibility does not guarantee inclusion.
